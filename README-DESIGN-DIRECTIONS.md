# Selected Direction: Glyph Ledger

## Design Movement

**Early terminal interface meets technical field manual.** The layout borrows the density and intentionality of retro command panels, but avoids a copy-paste cyberpunk look by using a small, monochrome navy instrument system rather than neon gradients.

## Core Principles

1. **One visual gesture per section.** The header carries the personality; sections below stay compact and structured.
2. **Controls, not decorations.** Badges, links, and disclosure controls should communicate an action or source.
3. **Live data is subordinate.** Dynamic markers are inside the field log, so the personal profile does not feel like generated telemetry.
4. **Sparse color, high intent.** Blue is signal, coral is alert, and slate is structure.

## Color Philosophy

The profile follows GitHub’s dark canvas rather than fighting it. A near-obsidian badge field `#0B1120`, powder-blue signal `#64C8FF`, soft white `#E6EDF3`, slate `#8B949E`, and coral `#FF7A59` will create hierarchy without a rainbow badge wall.

## Layout Paradigm

The page is a **vertical signal path**: identity command at the top, project routes, instrument band, live telemetry row, then an expandable field log. The dense automated content is deliberately kept below the primary portfolio scan.

## Signature Elements

1. A native monospace terminal principle line below the name.
2. Uniform dark “command” badges for navigation and technology groups.
3. Compact numbered project routes in place of a large generic project table.

## Interaction Philosophy

Every prominent visual item is a link to a concrete source. The field log uses GitHub’s native disclosure control. Live stats are wrapped in profile or repository links rather than being dead visual cards.

## Animation

The profile relies on no external animated or statistics-card service. Optional motion can be added later only if it has a stable source and is not required for navigation or understanding.

## Typography System

Use GitHub’s native sans-serif for body scanning and **JetBrains Mono** in the animated principle line and inline command labels. Headings remain short, direct, and sentence-fragment free.

## Brand Essence

**A compact public index for local-first products, security systems, and useful interface work.**

Deliberate. Technical. Grounded.

## Brand Voice

Headlines are concise system labels. CTAs use explicit verbs and destinations.

> `OPEN WORKSPACE →`

> `LIVE SIGNALS · LINKED TO SOURCE`

## Wordmark & Logo

The wordmark is plain-text `THE / NEOTIC`, treated as a terminal title rather than a decorative image. Its visual character comes from the surrounding command line and navigation controls, not an unclickable header graphic.

## Signature Brand Color

**Signal Blue — `#64C8FF`**
