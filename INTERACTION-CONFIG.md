## Three Active Controls

| Control | Destination | Purpose |
|---|---|---|
| `OPEN WORKSPACE` | Monolith Vault repository | Opens the primary security workspace |
| `BROWSE SOURCE` | Public repository index | Opens all visible projects and source work |
| `OPEN TERMINAL` | `Connect terminal` section in the README | Jumps to the connection area without leaving the profile |

These controls are fully functional GitHub README interactions: each uses a real link and retains GitHub-native navigation. GitHub README files cannot host a server-side backend, forms, database, or browser JavaScript. A true contact backend would need a separate web application and a real contact destination supplied by the user.
