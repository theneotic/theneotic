### `NODE_02` · MONOLITH VAULT
`CLIENT-SIDE CRYPTOGRAPHIC SECURITY` · `VERIFIED PRODUCTION`

Zero-dependency client-side cryptographic security utility and password entropy analysis workbench operating completely within the browser sandbox.

> **Architectural Bottleneck Solved:** Eliminated third-party npm supply-chain risk by engineering a pure mathematical entropy analyzer and vault interface running 100% client-side via native WebCrypto primitives.

`TypeScript` · `Vanilla JavaScript` · `Semantic HTML5` · `CSS3 Architecture` · `WebCrypto API`  
[Inspect Source ↗](https://github.com/theneotic/Monolith-Vault) &nbsp;·&nbsp; [Live Workspace ↗](https://github.com/theneotic/Monolith-Vault/tree/main)

### `NODE_03` · F1 LIVE TELEMETRY HUD
`REAL-TIME DATA PIPELINES & VISUALIZATION` · `VERIFIED PRODUCTION`

High-frequency race telemetry ingestion pipeline with deterministic lap-delta calculations, sector timing matrices, and live tire degradation modeling.

> **Architectural Bottleneck Solved:** Structured high-frequency streaming race telemetry into deterministic differential graphs on HTML5 Canvas without UI thread frame drops.

`Python` · `TypeScript` · `Telemetry Ingestion` · `HTML5 Canvas / UI`  
[Inspect Source ↗](https://github.com/theneotic/f1-telemetry-dashboard) &nbsp;·&nbsp; [Telemetry Spec ↗](https://github.com/theneotic/f1-telemetry-dashboard/tree/main)

<br />

### `NODE_04` · MEGA CHAT ARCHIVE & FABRIC CORE
`HIGH-VOLUME STREAM PARSING & JVM MODDING` · `VERIFIED PRODUCTION`

High-throughput client-side parsing and indexing engine for massive exported communication archives paired with custom low-level JVM game extensions.

> **Architectural Bottleneck Solved:** Constructed a chunked stream parser capable of indexing and rendering massive exported chat archives smoothly in the DOM alongside low-overhead JVM Fabric client hooks without heap exhaustion.

`Java (Fabric API)` · `TypeScript` · `Vanilla JavaScript` · `JSON Stream Parsing` · `C Utilities`
